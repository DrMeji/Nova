# NOVA

**NOVA** is a desktop AI creation studio for Windows.

Chat with local or cloud models, generate images and video, build and edit projects on your PC, and keep your work in one place.

## Download (this is what you want)

Get the Windows installer from **[Releases](https://github.com/DrMeji/Nova/releases)**:

- **ARK-Setup.exe** — install NOVA on your PC (installer filename kept for compatibility with existing updaters)
- After install: **Settings → Updates → Check → Download** for newer builds

## Important: "Source code (zip / tar.gz)" on Releases

GitHub **always** adds two automatic links on every release page:

- Source code (zip)
- Source code (tar.gz)

Those are **not** the NOVA application. GitHub generates them from *this* public repo, which contains **only this README** (and a tiny guard file). There is **no** NOVA app source, UI code, or backend logic here.

NOVA's real source code is **private** and is not published on GitHub for download.

If you want NOVA, download **ARK-Setup.exe** only.
