# Live fail → research → fix → re-run loop

**Goal:** Do not deep-scan the whole coding surface. Deep-research **only what this Live invent failed to do**, patch that root cause permanently, re-run Live, repeat.

## Loop

1. **Live premium invent** — create on disk → Live → Ready (honest).
2. **Miss list** — score the Acc folder vs the brief. Each miss is a *why* (pipeline bug), not a taste note.
3. **Pick #1 miss** — highest severity that blocked Ready / blank Live / wrong product.
4. **Deep research** — peers (Cursor / Claude Code / Lovable / v0 / Devin) + our code path that caused it.
5. **Permanent fix** — gate, craft, assemble, verify — not a one-off Acc patch.
6. **Missing tab** — if chrome/settings were absent, add a Missing item in the same change.
7. **Re-run Live** — same premium bar; only clear a miss when the next invent proves it.
8. Repeat until Ready + Live pass with zero critical misses.

## Severity order

1. Blank / crash Live (syntax, undeclared refs)
2. Wrong product / ladder stamp (Card-one, invent-demo)
3. Brief fidelity (brand, hero, books, photos)
4. Sections landed but not mounted
5. Placeholder copy
6. Soft polish (tokens, DESIGN.md)

## Artifacts

- `scripts/live-premium-fail-loop.mjs` — invent + miss report
- `.tmp-live-fail-loop/latest-report.json` — last miss list
- `.tmp-live-fail-loop/history/` — per-iteration reports
