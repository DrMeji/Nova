# Create → Live canonical spine (1–12)

Peer pattern (Cursor / Bolt / Lovable) + Nova invent-loop lessons.

| # | Stage | Meaning |
|---|--------|---------|
| 1 | `hard-go` | This is Create, not Chat |
| 2 | `brief` | Freeze brand + must-haves |
| 3 | `disk` | Bind one project folder |
| 4 | `scaffold` | Bootable Vite shell |
| 5 | `floor` | Invent floor (hero/shop/story) that sticks |
| 6 | `npm` | Install vite **before** long invent |
| 7 | `craft` | Model invent = enrich only |
| 8 | `heal` | Remount + thin-hero top-up |
| 9 | `syntax` | Syntax / import gate |
| 10 | `live` | Unlock Live when bars clear |
| 11 | `prove` | Prove **this** brand painted |
| 12 | `ready` | Hand back (Live≠quality Ready) |

Source: `THIN_CREATE_STAGES` / `formatThinCreateSpineStatus` in `src/lib/createThinPath.ts`.  
Chat statuses are pushed from `src/lib/chatTurnHandlers/create.ts`.
